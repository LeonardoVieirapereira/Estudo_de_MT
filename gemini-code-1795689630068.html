01

Estatística: conceito e uso

A Estatística é a ciência matemática dedicada à coleta, organização, análise, interpretação e apresentação de dados numéricos para apoiar a tomada de decisões sob incerteza.

Estatística Descritiva

Organiza, resume e descreve as características principais de um conjunto de dados por meio de tabelas, gráficos e medidas (média, mediana, etc.).

Estatística Inferencial

Utiliza dados de uma amostra para fazer generalizações, previsões e testes de hipóteses sobre toda uma população.

02

Pesquisa estatística

Uma investigação estatística segue etapas rigorosas para garantir que as conclusões sejam confiáveis e livres de vieses:

1. Definição do Problema → 2. Planejamento → 3. Coleta de Dados → 4. Apuração/Crítica → 5. Apresentação (Tabelas/Gráficos) → 6. Análise e Interpretação

Censo vs. Amostragem: Quando investigamos 100% dos elementos, realizamos um Censo (ex: Censo Demográfico do IBGE). Quando investigamos apenas uma parcela representativa, fazemos uma Pesquisa Amostral.

03

População e amostra

População (Universo Estatístico — N)

É o conjunto total de elementos, indivíduos ou objetos que possuem pelo menos uma característica comum objeto de estudo.

Amostra (n)

É qualquer subconjunto finito e representativo extraído da população. Técnicas comuns: Aleatória Simples, Sistemática e Estratificada.

04

Tipos de variáveis

Variável é a característica observada em cada elemento da pesquisa. Elas dividem-se em dois grandes grupos:

Qualitativas (Categóricas)

Nominal: Não possui ordem natural (ex: cor dos olhos, estado civil, time de futebol).
Ordinal: Possui hierarquia ou ordem lógica (ex: escolaridade, nível de satisfação: ruim, regular, bom).

Quantitativas (Numéricas)

Discreta: Resulta de contagem, números inteiros (ex: número de filhos, gols marcados).
Contínua: Resulta de medição, assume valores reais em intervalos (ex: altura, massa, temperatura).

06

Representação gráfica

Os gráficos transformam tabelas numéricas em imagens visuais imediatas. Os principais tipos são:

Colunas / Barras

Retângulos separados com alturas/comprimentos proporcionais às frequências. Ideal para comparar categorias discretas.

Setores (Pizza) e Linhas

Setores: Mostra proporções de um todo (360°).
Linhas: Ideal para séries temporais (evolução ao longo do tempo).

07

Histograma de frequência

O Histograma é um gráfico de barras justapostas (coladas umas às outras) usado especificamente para variáveis quantitativas contínuas agrupadas em intervalos de classe. A base representa a amplitude da classe e a altura representa a frequência.

08

Medidas de tendência central para dados não agrupados

Resumem um conjunto de dados individuais (x₁, x₂, ..., xₙ) em um único valor representativo:

• Média Aritmética (x̄) = (x₁ + x₂ + ... + xₙ) / n
• Mediana (Md) = Valor central do rol ordenado (se n par, média dos dois centrais)
• Moda (Mo) = Valor que aparece com maior frequência no conjunto

Moda e Mediana para dados agrupados sem intervalo de classe

Quando os dados discretos já estão organizados em uma tabela de frequência simples (valores pontuais xᵢ e frequências fᵢ):

Moda (Mo)

Basta observar a coluna de frequência absoluta (fᵢ) e identificar qual valor de xᵢ possui a maior frequência.

Mediana (Md)

Calcula-se a posição central P = n / 2 (ou (n+1)/2) e localiza-se na coluna de Frequência Acumulada (Fᵢ) o primeiro valor maior ou igual à posição.

10

Medidas de tendência central para dados agrupados sem intervalo de classe (Média Ponderada)

Para calcular a Média Aritmética quando há repetição registrada na tabela de frequências sem intervalos, multiplicamos cada valor xᵢ pela sua respectiva frequência fᵢ:

x̄ = ∑(xᵢ · fᵢ) / ∑fᵢ onde n = ∑fᵢ

Exemplo usando a tabela do tópico 05: x̄ = (6·4 + 7,5·8 + 9·6 + 10·2) / 20 = (24 + 60 + 54 + 20) / 20 = 7,9.

11

Medidas de tendência central para dados agrupados com intervalo de classe I

Quando os dados estão divididos em classes (ex: 10 ⊢ 20), utilizamos o Ponto Médio (pmᵢ) de cada classe como representante:

• Ponto Médio: pmᵢ = (Limite Inferior + Limite Superior) / 2
• Média (x̄) = ∑(pmᵢ · fᵢ) / n
• Moda Bruta (Mo) = Ponto médio da classe modal (classe de maior fᵢ)
• Mediana (Md) = Lᵢ + [ ((n/2 - F_ant) / f_md) · h ]

Onde Lᵢ é o limite inferior da classe mediana, F_ant é a frequência acumulada anterior, f_md é a frequência da classe mediana e h é a amplitude do intervalo.

12

Medidas de dispersão

Medem o grau de espalhamento ou variabilidade dos dados em torno da média. Dois conjuntos podem ter a mesma média, mas dispersões totalmente diferentes.

• Amplitude Total (AT) = X_máx - X_mín
• Variância Populacional (σ²) = ∑(xᵢ - x̄)² / n | Amostral (s²) = ∑(xᵢ - x̄)² / (n - 1)
• Desvio Padrão (σ ou s) = √Variância
• Coeficiente de Variação (CV) = (s / x̄) · 100%
13

Quartis

Os Quartis são medidas separatrizes que dividem o conjunto de dados ordenado em 4 partes iguais, cada uma contendo 25% das observações:

Q₁ (Primeiro Quartil — 25%)

Separa os 25% menores valores dos 75% maiores. É a mediana da primeira metade dos dados.

Q₂ (50%) e Q₃ (75%)

Q₂: Coincide exatamente com a Mediana.
Q₃: Separa os 75% menores valores dos 25% maiores. Amplitude Interquartil: AIQ = Q₃ - Q₁.

14

Box-plot (Diagrama de Caixa)

O Box-plot sintetiza visualmente 5 medidas fundamentais: Mínimo, Q₁, Mediana (Q₂), Q₃ e Máximo, permitindo identificar rapidamente simetria e valores discrepantes (outliers).

15

Construção e conversão de dados entre gráficos estatísticos

Converter dados entre formatos (Tabela ↔ Setores ↔ Barras) exige proporcionalidade matemática:

Ângulo no Gráfico de Setores (α) = (fᵢ / n) · 360° ou Percentual (%) · 3,6°

Conversor Interativo: Tabela ↔ Gráfico de Barras / Setores

16

Diagrama de ramos e folhas

Criado por John Tukey, o Diagrama de Ramos e Folhas organiza dados numéricos mantendo os valores originais visíveis. O ramo representa os algarismos iniciais (ex: dezenas) e a folha o último algarismo (ex: unidade).

Critérios de seleção e adequação de gráficos estatísticos

Escolher o gráfico errado pode distorcer a interpretação dos dados. Siga este guia de adequação:

Tipo de Gráfico Quando Usar (Adequação) Quando Evitar
Colunas / Barras Comparar quantidades entre categorias distintas ou variáveis discretas. Muitas categorias (> 15) ou dados contínuos agrupados em classes.
Setores (Pizza) Mostrar composição percentual de um todo (máximo 5 ou 6 fatias). Valores muito próximos entre si ou séries temporais.
Linhas Evolução de uma variável contínua ao longo do tempo (séries históricas). Categorias nominais sem relação de continuidade (ex: marcas de carro).
Histograma Distribuição de frequência de variáveis quantitativas contínuas. Variáveis qualitativas nominais.
Box-plot Comparar dispersão, mediana e detectar outliers entre grupos. Público leigo sem familiaridade com quartis ou amostras muito pequenas (n < 5).
